# Landing Estudos

Landing page responsiva para um aplicativo ficticio de organizacao de estudos.

## Objetivo

Praticar HTML semantico, CSS responsivo, composicao visual, secoes comerciais e interacoes simples com JavaScript.

## Demo

Link: https://prgvvheitor.github.io/landing-estudos/

## Funcionalidades

- Hero com proposta de valor.
- Menu responsivo.
- Secao de beneficios.
- Planos.
- Perguntas frequentes com acordeao.
- Chamada para acao.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como rodar

Abra o arquivo `index.html` no navegador.
